Building Photo Archive

The Building Photo Archive serves as both a storage bucket for the images of each building as well as the tool to view them.
Each image can be viewed as a 3D object, although not as a panorama. 
Additionally, panoramas should not be displayed--they won't show up properly.

For each building, a specific JavaScript file with two arrays will be used.
One array is for image file names (and extensions) which will be served under a specific file path.
The second array contains the "name" of each image and its location (for example, a picture of a plant in room 208 will be in the format of Plant,Room 208).
